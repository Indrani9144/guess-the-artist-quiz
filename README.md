# Guess the Artist Quiz 🎨

A full-stack interactive quiz application where users guess the artist based on artworks.

## Features
- Dynamic question generation using external APIs
- Real-time score tracking
- Responsive UI
- Backend logic for validation and scoring

## Tech Stack
- Frontend: HTML, CSS, JavaScript, EJS
- Backend: Node.js, Express
- APIs: External artwork APIs
- Deployment: Render
